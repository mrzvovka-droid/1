# Изображения

## instructor.png

Обтравленный кадр инструктора у учебного автомобиля: PNG с прозрачным фоном.

Используется дважды из одного файла:

- хиро — целиком, человек и машина, выравнивание по нижнему краю;
- точка 02 «Знакомство с инструктором» — тот же файл, кроп на человека
  (`object-position: 50% 12%`).

Пока файла нет, оба места показывают помеченную заглушку и подставляют
фотографию автоматически, как только файл появится. Никакой правки разметки
для этого не требуется.

Рекомендуемый размер: не меньше 1200 px по короткой стороне.
