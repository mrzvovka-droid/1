# ОСЬ — дизайн-референсы сайта (8 секций)

Комплект сгенерирован по скиллу `imagegen-frontend-web` на основе документа
«Стратегии по направлениям маркетинга» (запуск биржи цифровых активов в российском
правовом контуре).

> **Бренд-нейм «ОСЬ» — плейсхолдер для компа.** Перед любым внешним использованием
> заменить на реальное имя и проверить на конфликты с существующими товарными знаками.

## Как это сделано

В сессии не было генератора изображений. Секции собраны как HTML-компы и отрендерены
в Chromium (Playwright) — каждая в отдельный горизонтальный PNG. Побочный эффект:
референсы не «нарисованы», а свёрстаны, поэтому из них можно брать реальные значения
(типографика, отступы, цвета), а не пересобирать на глаз.

Фотографии недоступны — вся атмосфера (ночной силуэт Сити, песочное поле,
кадр студии) построена на CSS-градиентах, зерне и геометрии. При продакшене эти
плашки заменяются арт-дирекшн-съёмкой.

```
node shoot.js        # перерендерить все секции
node shoot.js 03     # перерендерить одну
```

Шрифты ставятся системно (Golos Text, Inter, JetBrains Mono с Google Fonts).
